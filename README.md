# QR Master

QR Master is an offline-first Progressive Web App for scanning and generating QR codes entirely in the browser.

## Features
- Generate QR codes from text, links, phone numbers, emails, Wi-Fi credentials, and custom content
- Scan QR codes from the device camera or uploaded images
- Copy content and download generated QR codes as PNG
- Fully responsive on mobile, tablet, and desktop
- Installable as a Progressive Web App with offline support

## Run locally
1. Open the project folder in a browser or serve it from a simple local server.
2. If you want a local server, run:
   - Python: `python -m http.server 8000`
3. Open: `http://localhost:8000`

## PWA install
- On mobile, use the browser install option.
- On desktop, use the install button that appears in the interface.

## Privacy
- No analytics, tracking, or external data collection.
- All QR processing happens locally in the browser.
